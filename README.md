# Chatbot-Febeu
Implementar o chatbot da empresa Febeu
1. psycopg
O Psycopg é um driver que permite às aplicações Python comunicar com o PostgreSQL.

Com ele podemos:
- Estabelecer ligações à base de dados.
- Executar consultas SQL.
- Inserir, actualizar e eliminar registos.
- Recuperar resultados das consultas.
2. asyncpg
O asyncpg também permite comunicar com PostgreSQL, mas foi desenvolvido especificamente para trabalhar com operações assíncronas através de asyncio.
